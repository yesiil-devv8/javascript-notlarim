\# JavaScript Nedir?

\## 1. Tanım

JavaScript, web sayfalarına etkileşim ve davranış kazandırmak için kullanılan bir programlama dilidir.

HTML sayfanın yapısını oluşturur, CSS görünümünü düzenler, JavaScript ise sayfanın nasıl davranacağını belirler.

\## 2. Nerelerde Kullanılır?

\- Web sayfalarında butonlara işlev kazandırmak
\- Formlardaki bilgileri kontrol etmek
\- Dinamik içerikler oluşturmak
\- React gibi kütüphanelerle web arayüzleri geliştirmek
\- Node.js ile sunucu tarafında programlama yapmak

\## 3. İlk JavaScript Kodum

```javascript

console.log("Merhaba Dünya!");

```
\### Açıklama

\- `console.log()` ekrana veya geliştirici konsoluna bilgi yazdırmak için kullanılır.
\- `"Merhaba Dünya!"` bir metin değeridir.
\- Noktalı virgül (`;`) komutun sonunu belirtmek için kullanılabilir.

\## 4. Hatırlamam Gerekenler

\- JavaScript ile Java farklı programlama dilleridir.
\- JavaScript kodları hem tarayıcıda hem de uygun çalışma ortamlarında çalıştırılabilir.
\- Kod yazmayı öğrenmenin en iyi yollarından biri örnekleri kendim yazıp denemektir.
